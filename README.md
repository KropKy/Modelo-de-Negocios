# Mi Modelo de Negocio

Business Model Canvas guiado paso a paso, pensado para que cualquier persona —desde estudiantes hasta dueños de un negocio en marcha— pueda construir o revisar su modelo de negocio sin necesidad de conocimientos técnicos.

🔗 **Demo en vivo:** `https://TU-USUARIO.github.io/TU-REPOSITORIO/`
*(reemplaza esta URL una vez publicado con GitHub Pages — ver instrucciones abajo)*

## ¿Qué es esto?

Una aplicación web de una sola página (HTML/CSS/JS, sin dependencias externas ni backend) que guía a la persona a través de los 9 bloques del Business Model Canvas de Osterwalder y Pigneur:

- Segmentos de clientes
- Propuesta de valor
- Canales
- Relación con clientes
- Fuentes de ingresos
- Recursos clave
- Actividades clave
- Socios clave
- Estructura de costos

## Características

- **Modo "Paso a paso"**: un bloque a la vez, con la pregunta guía, una explicación y un ejemplo.
- **Modo "Mapa completo"**: los 9 bloques en la disposición clásica del Canvas.
- **Selector de perfil**: las preguntas se adaptan según si la persona está empezando desde cero o ya tiene un negocio operando.
- **Marcadores de riesgo**: señala los bloques de Segmentos de clientes y Propuesta de valor como los de mayor riesgo a validar primero.
- **Estados por bloque**: Hipótesis / Por probar / Con evidencia, para distinguir lo que se supone de lo que ya se comprobó.
- **Revisión estructural**: comprueba que los bloques relacionados entre sí estén completos y sean coherentes.
- **Apoyo con IA**: genera automáticamente un prompt listo para copiar y pegar en cualquier herramienta de inteligencia artificial (ChatGPT, Claude, etc.), en tres modos: Aprender, Mejorar y Cuestionar.
- **Guardar y abrir**: exporta el modelo como archivo `.json` para respaldarlo o compartirlo, y permite reabrirlo después.
- Todo el contenido se guarda automáticamente en el navegador (`localStorage`) — no requiere cuenta ni conexión a internet para usarse.

## Cómo publicarlo con GitHub Pages

1. Sube este repositorio a GitHub (si no lo has hecho: `git init`, `git add .`, `git commit -m "Primera versión"`, y súbelo a un repo nuevo).
2. En el repositorio, ve a **Settings → Pages**.
3. En "Source", elige la rama `main` y la carpeta `/ (root)`.
4. Guarda. En un par de minutos la app estará disponible en `https://TU-USUARIO.github.io/TU-REPOSITORIO/`.

## Cómo usarlo en local

No requiere instalación ni servidor. Basta con abrir `index.html` directamente en cualquier navegador moderno.
